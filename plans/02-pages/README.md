# Page specifications (§5)

Each spec links to the exact source page in the [full extracted brief](../brief-extracted.txt), whose tables retain widget fields, source, cadence, history, interactions and failure behavior. Consult the [PDF](../VyOS-ViewOnly-Dashboard-Design-Brief.pdf) for original formatting.

Common states: render last known state; skeleton only when never collected; empty is informational with a copyable configuration command; hide unsupported modules but explain direct links; mark stale when age exceeds twice cadence; source errors retain dimmed last-good data, report error and last success; partial failures name the failed portion. Prefer structured sources; release-specific parser mapping and golden files cover text fallbacks.
