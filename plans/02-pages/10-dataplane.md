# Dataplane (§5.10; PDF pp. 20–21)

Optional hardware dataplane module (capability-detected; absent means hide the section or show generic kernel equivalents). Implements the **Two-Plane Offload Model** for NXP LS1046A / ASK2: **Plane A (Hardware)** reads FMan MAC/port `ethtool -S` counters, ASK2 hardware flow table (`fe_flow` debugfs, capped entries, parsed inside `vyview-probe` with defensive schema guards since debugfs is not a stable ABI), QMan/BMan/FQ congestion (`fsl_dpa`/`qbman`), CAAM crypto job counters, and WireGuard fast-path RX (`wgfp_rx`); **Plane B (Kernel)** reads `netdev`, `conntrack`, `nf_flowtable`, and `xfrm_stat`. Reconciles both planes to expose per-port and per-flow **`offload_ratio`**, slow-path pps, CEETM queues, BMan pools (`<30%` warn / `<15%` crit), per-core IRQ/softirq/`softnet_stat` (imbalance hint `>2×` mean), optional WireGuard & IPsec CAAM acceleration, planned ACL/DDoS drops, and Suricata shunt. Optionally supports a capability-detected **VPP stats segment / AF_XDP** adapter when VPP owns NIC queues. Full table: [extraction](../brief-extracted.txt), pages 20–21.
